# InsightBoard — Week 2 Interactive UI Components

## Objective
Build reusable interactive front-end components using HTML, CSS and vanilla JavaScript.

## Components
- Accessible tab system with keyboard arrow navigation
- Expandable accordion with ARIA state
- Modal dialog with Escape and backdrop close behavior
- Responsive mobile navigation
- DOM manipulation and event handling

## Run
Open `index.html` directly in a browser.

## Testing
Test tab switching, Arrow Left/Right keyboard navigation, accordion open/close, modal open/close, Escape key, backdrop click and responsive navigation.
