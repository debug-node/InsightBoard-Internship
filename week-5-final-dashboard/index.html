ENGINEERING PRACTICES

Architecture & Internship FAQ

How this 5-week project implements clean frontend engineering, accessibility, and dynamic JSON data.

The application calls the browser fetch('data.json') API with cache controls. Upon receiving the JSON response, the dashboard parses KPI metrics, monthly revenue records, channel traffic percentages, product catalogs, and transactions. Every component in the UI renders from this state object. If data.json is modified, clicking "↻ Refresh data" instantly re-renders the UI.

Filtering and sorting are purely functional and state-driven. The state object preserves active search query, status filter, sort column, and ascending/descending order. When any filter changes, the pipeline filters the transaction array, sorts by data type (numerical for amounts, chronological for ISO dates, alphabetical for text), updates table rows, and announces the row count via ARIA live regions.

InsightBoard adheres to WCAG 2.1 AA standards: semantic landmarks (main, nav, header, footer, section, article), a top-level Skip Link, proper table semantics with th scope="col" and aria-sort, complete keyboard navigation with visible focus rings (:focus-visible), focus trapping inside modal dialogs, Escape key dismissal, and prefers-reduced-motion media query support.

The project requires zero runtime libraries or heavy chart packages. Scripts are deferred, DOM queries are cached, search inputs are debounced, event delegation is used on interactive tables, and charts are rendered with lightweight CSS/DOM flex elements.

Dashboard Summary & Guide

Welcome to the InsightBoard internship mini web application. This project demonstrates mastery across the 5-week curriculum:

  • Week 1: Responsive semantic layout, Flexbox, and CSS Grid
  • Week 2: Interactive vanilla JS components: tabs, accordion, and modal
  • Week 3: WCAG accessibility, focus trapping, landmarks, and ARIA live regions
  • Week 4: Performance optimizations, deferred JS, and zero dependencies
