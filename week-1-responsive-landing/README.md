# InsightBoard — Week 1 Responsive Landing Page

## Objective
Create a responsive landing page using semantic HTML5, modern CSS and vanilla JavaScript.

## Features
- Responsive navigation with mobile menu toggle
- Hero section with analytics preview
- Feature highlights
- Three-step workflow section
- Responsive CTA and footer
- Flexbox and CSS Grid layouts
- Mobile-first responsive breakpoints
- Basic accessibility labels for navigation and dashboard chart

## Run
Open `index.html` in a browser. No build tools or dependencies are required.

## Testing
Test at desktop, tablet and mobile widths. Verify navigation links and the mobile menu toggle.
