# InsightBoard — Week 4 Performance Optimization

## Objective
Analyze and improve frontend performance while preserving functionality and accessibility.

## Optimizations Applied
- JavaScript loaded with `defer`
- Stylesheet preloaded
- Lightweight inline SVG instead of a charting library
- No unnecessary third-party dependencies
- Reusable CSS to reduce duplication
- Responsive layout with efficient media queries
- Reduced-motion support
- Visibility-aware JavaScript behavior
- Simple static architecture requiring no build step
